## Generate PDF pitch

1. Open `ONE_PAGE_PITCH_EN_HI.html` in Chrome or Edge.
2. **Ctrl+P** → Destination: **Save as PDF**.
3. Paper: A4 · Margins: Default · **Background graphics: ON**.
